# 路线图与优先级

> 优先级标记：P0 必须具备；P1 提升差异化；P2 后续生态。并非开发排期承诺。

> 进度以 2026-10-21 的当前实现为准。设计项不代表已完成；“基础版已具备”表示最小闭环已实现，仍可能需要可靠性、安全和体验完善。

## P0：最小可用闭环

**目标**：能够配置、连接、回复、定位问题。

- **基础版已具备**：Node 服务与 Web 工作台、官方 QQ Bot 的扫码和 AppID/AppSecret 接入、提供商与模型配置、基础对话测试、人格管理、群/私聊会话管理、`/new` 与 `/compact` 命令、运行日志、Pi Agent Loop 与 Tools 配置。
- **基础版已具备**：群/个人对象配置人格、模型、Tools 开关及功能开关；群聊智能插话有全局限制、纯概率/智能判断模式和决策记录，且已完成真实群聊验收。
- **仍待补齐**：首次启动引导；完整消息 Trace 与统一关联；密钥保护与权限审计；正式数据库持久化、备份与恢复。
- 当前只提供 QQ 官方 Bot 接入；其他平台或协议未实现，也没有为第二种接入实现可用适配器。

## P1：社交 Agent 体验

- **基础版已具备**：支持配置多个 Bot 实例（同时最多启用一个）、多个提供商/模型，并可为群或个人选择人格和模型。
- **基础版已具备**：群聊智能插话、全局日发送上限/静默时段、概率或模型判断、群级启用、冷却和运行决策记录；更细的注意力/话题机制仍待完善。
- **部分实现**：Tools 全局配置与群/个人开关已接通；工具/插件/Skills 的安装、生命周期和细粒度授权尚未完成。
- **未实现**：表情包资产导入、打标、检索和发送；调试台目前是基础对话测试，Trace 查询、历史回放和完整上下文检查仍待实现。
- 会话目前按群/个人对象管理配置并呈现多个会话；完整的多层配置继承与生效来源展示尚未实现。

## P2：生态与高级能力

- MCP 服务管理、图像生成、STT/TTS、长期记忆与知识库。提供商页面的 TTS 和生图入口目前只是占位。
- 定时任务、主动发起、自动化规则、高级授权。
- 扩展 UI、第三方插件包管理、跨平台支持。
- 高级运营统计、多实例运行、可选远程同步。

## 阶段性验收

| 阶段 | 能力证明 |
|---|---|
| P0 | 基础配置与 QQ 收发闭环已完成；完整 Trace、安全、备份/恢复与数据库持久化仍未达成 |
| P1 | 群级人格/模型配置与智能插话已完成基础验收；表情包闭环和完整配置来源展示仍未达成 |
| P2 | 插件安装后新增能力与设置页，权限可控，主动任务可以审计与撤销 |

## 必须避免的范围膨胀

- 不要求所有高级功能在前端成品之前完成；先给导航占位与状态解释。
- 不以“兼容每一个 Pi 扩展”作为核心验收；只保证声明过的兼容接口。
- 不为一次部署引入复杂集群、独立消息总线或强依赖云基础设施。
