# 导航层级与页面关系

## 左侧边栏

```text
┌ Miubot                  [运行状态] ┐
│ 概览                              │
│ 平台                              │
│ 提供商                            │
│ 人格                              │
│ 会话                              │
│ 调试台                            │
│                                   │
│ ▾ 高级配置                       │
│   表情包                          │
│   主动行为                        │
│   MCP                             │
│   Skills                          │
│   记忆与知识库                    │
│   定时任务                        │
│   扩展插件与自动化规则            │
│                                   │
│ 运行日志                          │
│ 设置                              │
└───────────────────────────────────┘
```

优先级：**概览 → 连接 → 模型 → 人格 → 会话 → 调试**；高级功能收纳在默认折叠区域；日志与设置底部固定。窄屏侧栏收起为图标，移动端改抽屉式导航。

## 页面关系

| 从哪里 | 到哪里 | 为什么 |
|---|---|---|
| 首页 Bot 状态卡片 | 平台 / 某 Bot 详情 | 修复连接问题 |
| 首页提供商状态 | 提供商 | 新增模型或故障排查 |
| 首页人格卡片 | 人格编辑 | 立即修改默认人格 |
| 平台的最近消息 | 会话 / 对应聊天 | 查看完整聊天记录 |
| 会话的模型选择 | 提供商详情（新页或抽屉） | 排查模型配置 |
| 会话的某条回复 | 调试台 Trace | 查看为何回复 / 未回复 |
| 日志的 Trace ID | 调试台 Trace | 跨模块关联定位 |
| 高级配置的授权 | 会话能力覆盖 | 明确哪个群能使用能力 |

## 全局对象与上下文

顶部全局栏应体现当前工作台实例与服务连接状态。不要设置一个会偷偷改变全局配置的「当前 Bot」切换器；需要筛选时在列表页显式显示 Bot 过滤条件。

每个功能页统一布局：

1. 标题与简短说明，不叠加大号口号。
2. 中等优先级的主要操作区：添加、测试、搜索、筛选。
3. 主内容区域：列表或详情。
4. 抽屉/对话框用于低频编辑；复杂向导可占独立页面。

## 命名约定

- 侧栏使用 **「会话」**，不使用「对话配置」，因为其含消息历史、上下文与会话设置。
- 侧栏使用 **「主动行为」**，内部区分智能插话与主动发起。
- 使用 **「提供商」** 管理 API 端点和模型，避免与平台概念混淆。
- **「调试台」** 面向某次决策/执行；**「运行日志」** 面向系统事件时间线。

## 全局空状态与导航兜底

- 首次启动：首页出现三步引导（平台 → 提供商 → 人格），每步可跳转。
- 未连接 Bot：平台页显示添加入口；会话页显示解释性空状态，不报错。
- 无可用模型：在会话和调试台阻止发送并给出前往提供商入口。
- 配置被禁用或删除：保留失效引用并标警告，提供重新选择或恢复继承，不静默切换到未知模型。
