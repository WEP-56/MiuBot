# 人格 · Persona 管理

**位置**：侧栏 / 人格 · **目标**：创造、测试、管理多个可复用的人格，同时与模型、权限、会话绑定解耦。

## 页面结构

```text
人格                                     [+ 新建人格] [搜索]
[人格卡片/列表：名称、简介、版本、引用会话数]
点击进入人格编辑：
  基本资料 | 核心设定 | 表达偏好 | 资源关联 | 预览测试
```

## 配置内容

| 分区 | 字段 |
|---|---|
| 基本资料 | 名称、头像、介绍、标识 ID、标签 |
| 核心设定 | System Prompt / 角色背景 / 行为边界描述 |
| 表达偏好 | 语气、语言、回复长短、表情使用倾向 |
| 资源关联 | 可选记忆范围、知识库、默认 Skill 偏好（不直接赋予执行权限） |
| 版本 | 最后修改时间、变更历史、回滚/复制 |

## 关键交互

- 人格列表支持新建、复制、导入、导出与删除；删除前展示引用该人格的会话。
- 编辑页保存和测试明确分离；可选“测试未保存草稿”，标注结果不代表正式生效。
- 右侧即时聊天预览：切换测试模型、选择模拟会话上下文、清空/保留试聊记录。
- 修改已生效的人格时，明确是否新消息立即采用新版本，旧消息不被重写。

## Persona 的职责边界

- 人格定义表达方式和角色设定，不接管平台凭据、模型认证或工具授权。
- 系统安全限制、会话工具授权高于人格描述；人格不能仅凭文字授予 Shell、文件或跨群读取权限。
- 人格引用的是资源标识；例如引用了记忆库也不代表所有会话都可读取全部记忆。

## 空状态与反馈

- 默认内置/引导创建一个空白人格（保留用户修改能力），不要强迫套复杂模板。
- 导入失败解释格式或版本不兼容；不可在不询问的情况下覆盖同名人格。
- 被多个群引用时保存需展示受影响范围，提供复制新版本再切换选项。

## 验收

- 能新建两个人格、分别在群聊中绑定，并在同模型下进行对比测试。
- 人格变更可以追踪到版本和修改时间；会话可显示当前使用哪一版本。
- 用户不会误以为“人格选择了工具”就拥有调用权限。
