# 运行日志 · 全局诊断

**位置**：侧栏底部 / 运行日志 · **目标**：定位连接、处理、模型请求、Agent 执行、系统运行的问题，并可由 Trace 串联。

## 日志视图

| 视图 | 范围 |
|---|---|
| 消息处理 | 消息收到、排队、过滤、回复、发出失败（全文消息浏览仍在会话） |
| 平台事件 | 登录、认证、心跳、断连、重试、成员事件 |
| Agent 执行 | 模型路由、上下文构建、工具调用、回退与错误 |
| 系统 | 服务启动、数据库、插件加载、定时任务与性能 |

## 列表交互

顶部时间范围、级别、Bot、会话、模块、Trace ID 搜索；日志列表逐条展示时间、级别、模块、摘要、耗时。点击展开结构化字段和同 Trace 关联事件。支持暂停实时滚动、下载脱敏诊断包。

## 日志规范

- 所有进站、模型调用、工具和出站事件带一致 `traceId`；并发 Tool 可增加 `spanId / parentSpanId`。
- 使用结构化时间戳、事件类型、严重程度、来源模块、错误码与可恢复建议。
- 不把高频无意义内部日志当错误展示；默认只显示对用户有帮助的事件，Debug 级按需启用。
- API Key、Cookie、WS Token、Session 凭据和私人消息敏感片段默认脱敏，必要时允许配置消息内容保留期限。

## 状态与数据保留

- 日志不足/不存在显示空状态；系统磁盘不足时提供清理入口。
- 默认提供体积或保留天数上限；按原始消息、Agent Trace、系统日志分类管理。
- 导出前明确可能含用户消息及模型提示词，并允许附加脱敏级别。

## 验收

- 能从断线日志定位具体实例并直达平台详情。
- 能从一条 Agent 错误看到相关模型回退和回复状态。
- 复制的诊断信息不会包含原始密钥。
