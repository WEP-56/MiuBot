# 记忆与知识库 · 多层上下文

## 目标

为社交场景提供长期关系/偏好记忆与外部参考资料，同时严格避免私聊、跨群和跨 Bot 的信息泄漏。

## 三种不同的信息

| 类型 | 内容 | 存储/生命周期 |
|---|---|---|
| 消息历史 | 原始群聊/私聊消息与媒体事件 | 会话归档，由保留策略管理 |
| 长期记忆 | 被提取的稳定偏好、事实、关系摘要 | 独立记忆实体，带来源与时间 |
| 知识库 | 用户主动导入的文档、网页整理内容 | 集合、文档、分块和索引 |

## 页面结构

```text
记忆与知识库
[长期记忆] [知识库] [提取/检索设置]
长期记忆：范围筛选、来源、内容、最近访问、编辑/删除
知识库：集合列表 → 文件与分块状态 → 检索测试
```

## 长期记忆

推荐字段：`id, scope, subjectId, content, sourceConversationId, sourceMessageIds, createdAt, updatedAt, confidence, expiresAt, reviewedAt`。可按全局/Bot/群/个人明确界定可见范围；用户可禁用自动提取并删除相关记忆。

- 自动提取不应把单次玩笑立刻写成永久事实；增加稳定性验证与人工纠错能力。
- 原始消息删除后，是否级联删除衍生记忆必须由明确策略决定，且在 UI 提示。
- 模型判断的记忆不等于真实身份事实；可以显示来源、置信程度和最后确认时间。

## 知识库

支持创建集合、导入支持格式的文档、分块、向量化/关键词索引、检索测试与删除。可选择具体集合给 Bot 或某会话读取；未授权的集合不参与检索。

## Context Core 中的使用

当前任务产生 `ContextRequest`，组合近期消息、引用链、相关长期记忆、可用知识片段和人格，在 Token 预算内组装。**上下文压缩不能删除原始历史**；必须有单独保留和清理策略。

## 隐私与安全

- 强制检索时带 `scope` 过滤，不仅依赖 Prompt 要求“不要透露”。
- 私聊记忆默认只归属当前用户及 Bot，不跨会话公开；群记忆默认只对本群可见。
- 日志与导出要标明可能包含敏感聊天内容，支持脱敏、访问控制和删除。

## 验收

- 两个群同名成员不会发生记忆误关联；私聊事实不能被另一个群调用。
- 记忆条目可编辑、查看来源并删除；知识库集合可授权给指定会话。
- Agent 能看到实际检索到的摘要，管理员可在调试台解释上下文来源。
