# 表情包 · 导入、标注与检索

## 目标

让 Agent 能根据聊天语境使用合适的表情包，而非把整个表情包文件夹塞进每次 Prompt。

## 页面结构

```text
表情包                           [+ 导入] [批量标注] [搜索]
[全部] [已标注] [未标注] [待审核]
[相册式网格：预览 | 标签数量 | 来源 | 使用次数]
选中 → 预览 / 编辑描述与标签 / 可用范围 / 删除
```

## 数据

每项包含 ID、文件路径/媒体资源引用、格式与尺寸、内容哈希、来源、导入时间、描述、标签、标注来源（人工/AI）、审核状态、可使用平台范围、使用计数。使用内容哈希去重，保留可选同图不同分组关系。

## 标签体系

- **情绪**：开心、无语、委屈、得意、愤怒。
- **动作**：摸头、拥抱、挥手、躺平。
- **语境/用途**：安慰、嘲讽、感谢、道歉、晚安。
- **内容**：猫猫、狗狗、角色、文字梗。
- **使用限制**：私人、仅某 Bot/群可用、不适合公开环境。

## 导入/标注流程

1. 批量导入或从授权的会话消息里显式收藏。
2. 检查格式、大小与重复；保存文件，生成安全缩略图。
3. 初始状态为未标注；支持人工批量打标签。
4. 可选使用视觉模型自动描述、标签建议，进入待审核或按用户配置自动通过。
5. 标注通过后进入工具索引；标签变更触发索引更新。

## 给 Agent 的能力

建议暴露 `search_stickers(query, mood?, limit?)` 返回少量候选：`id / 描述 / 标签 / 缩略图引用 / 是否可用`；Agent 选择候选后由发送层将 ID 转为平台可发送媒体。语义检索和标签检索可组合使用；初期先做标签检索即可。

**切勿**让 Agent 拿磁盘任意路径作为可发送表情；发送时复查会话权限、媒体格式和平台能力。

## 边界和异常

- 不支持图片发送的平台，搜索 Tool 不应返回“可直接发送”的假结果。
- 未审核标签只能给管理员预览，不默认用于自动回复。
- 删除某表情包时同步清理索引；已发送历史保留消息事实而不是悬空文件依赖。
- GIF / WebP 等动图支持取决于适配器和媒体转换能力。

## 验收

- 能批量导入、自动去重、人工加标签并搜索。
- Agent 可检索限定集合，不得访问未授权私有表情。
- 表情包不可发送时有明确失败原因与文本降级提示。
