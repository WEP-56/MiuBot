# Skills · 能力包管理

## 定位

Skills 为 Agent 提供可发现、按需读取的领域指导与资源，而不是传统意义上一个独立、自动拥有主机权限的可执行插件。Miubot 尽量借鉴 Pi 的 Skills 使用方式，并为聊天场景增加范围、可见性与授权。

## 页面结构

`已安装 / 可用 / 已禁用` Tab；每个 Skill 展示名称、简介、来源、版本/路径、适用范围、是否需要额外工具。详情支持查看说明、依赖、关联工具、使用记录和禁用原因。

## 生命周期

1. 从可信目录安装/导入本地 Skill（后续再考虑在线市场）。
2. 解析元信息与资源引用，提示潜在工具/命令依赖。
3. 管理员检查来源与文件内容并启用。
4. 对全局、Bot、会话定义是否可见，按需提供给 Agent。
5. 允许停用、更新、移除，并保留审计记录。

## 与 Pi 生态关系

- 优先兼容不依赖 Coding Agent 工作目录和终端 UI 的 Skill。
- 若 Skill 要求 Bash、读写项目文件等能力，不能仅因“已安装”就开放对应 Tool。
- 不承诺所有 Pi Skills 零修改可用；需要记录兼容性级别（可用、部分可用、不兼容）。

## 与插件区别

Skill 是 Agent 的领域工作说明和资源；Plugin 负责向宿主注册运行能力、后台事件或 Tool。一个 Skill 可以依赖插件提供的 Tool，但两者分别安装、启用和授权。

## 验收

- 能导入并解析一个纯文本 Skill，让被授权的测试会话可见。
- 会话未授权或相关 Tool 不存在时，界面能够解释为什么不能使用。
- Skill 的更新和禁用不会绕过宿主权限边界。
