# 高级配置 · 扩展能力总览

**位置**：侧栏 / 高级配置（可折叠组）。

## 设计原则

高级配置不是另一套“全局设置”，而是 **Agent 与系统扩展能力的管理入口**。默认折叠，不妨碍一般用户进行平台、模型、人格和会话设置。

## 子页面

| 页面 | 作用 | 会话层体现 |
|---|---|---|
| [表情包](01-表情包.md) | 导入、标注、检索表情素材 | 是否允许使用、使用集合 |
| [主动行为](02-主动行为.md) | 智能插话、主动发起、冷却与触发 | 每个群/人的启停及覆盖参数 |
| [MCP](03-MCP.md) | 外部 MCP 服务与 Tools | 授权哪些工具 |

| [记忆与知识库](05-记忆与知识库.md) | 长期记忆、知识资料与检索 | 当前会话能用哪些范围 |
| [定时任务](06-定时任务.md) | 单次、周期任务及执行记录 | 发送目标、允许条件 |
| [扩展插件与自动化规则](07-扩展插件与自动化规则.md) | 插件宿主与事件规则 | 能力是否授权和哪些规则有效 |

## 统一体验

每个能力页包含：`能力列表 / 当前状态 / 新增或安装 / 能力详情 / 授权范围 / 日志与运行状态`。如果一个能力尚未安装或外部服务离线，在会话配置中显示不可用原因，不应假装该工具仍可执行。

## 统一权限

- **注册 ≠ 启用 ≠ 授权**：插件装上只是注册能力；管理员启用之后还要决定允许哪些 Bot、群、人访问。
- 特定 Tool 可被授权给 Agent，但后台自动运行或监听消息还要有独立权限范围。
- 高危能力（发群消息、读外部资料、写文件、执行命令、调用自定义 Webhook）需更严格的访问控制与审计。
- 插件错误不能拖垮所有平台消息处理；至少需要隔离出错扩展并能快速停用。

## 统一状态

支持 `未安装 / 已安装待配置 / 已启用 / 降级 / 错误 / 已停用`。详细报错和最后运行时间可点击查看。MVP 可以只实现核心能力的 UI，占位项需明确“规划中”。
