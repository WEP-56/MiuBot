# 定时任务 · Agent 计划与主动发送

## 目标

支持一次性和周期性的后台 Agent 工作，但必须能准确追溯何时执行、以什么身份执行、是否给真实 QQ 用户发送过内容。

## 页面结构

```text
定时任务                             [+ 新建任务] [筛选]
任务列表：名称 | 触发计划 | 目标 Bot / 会话 | 下次运行 | 状态
任务详情：任务内容 / 时区与规则 / 权限 / 执行历史 / 暂停
```

## 任务字段

- 名称、任务类型（仅计算/生成草稿/发送消息）、任务输入 Prompt 或执行动作。
- 单次时间或周期计划，明确时区、错过执行策略、重复执行策略。
- 运行身份、使用人格、任务模型槽位、允许工具权限、目标 Bot/会话。
- 并发、最大执行时间、重试策略、预算、失败通知方式。

## 两类来源

1. **管理员手工创建**：通过 Web 表单并显式授权目标和发送副作用。
2. **Agent 创建建议**：Agent 可以提出任务草案，但涉及未来主动发消息或高风险工具时要走宿主权限与审批，不能仅凭群友一句话永久植入全局任务。

## 执行与审计

- 建议任务状态：草稿、启用、暂停、运行中、成功、失败、待审批。
- 每次执行有 runId、traceId、开始/结束时间、执行模型、工具结果与发送回执。
- 重试不能导致重复发送；需要幂等键与发送状态确认。
- 任务目标离线或平台不支持主动发送时，按已配置策略失败/延后，不无限堆积。

## 验收

- 能创建一次性任务、周期任务，并暂停、修改和删除。
- 涉及主动消息的任务必须显示目标并经过明确授权。
- 执行失败与重复执行被记录，能够追踪真实发送行为。
