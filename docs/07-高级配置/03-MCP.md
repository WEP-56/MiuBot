# MCP · 远程工具服务管理

## 目标

让管理员能够增加外部 MCP 服务并将其中工具授权给特定 Agent/会话，而不是让所有 QQ 群自动获得所有工具。

## 页面布局

```text
MCP                          [+ 添加服务器] [搜索]
服务器卡片：名称 | 连接方式 | 健康状态 | Tool 数量
点击详情：连接参数 / Tool 清单 / 授权范围 / 调用日志
```

## 基础能力

- 连接类型依据所集成的 MCP SDK 支持情况提供（如本地 stdio、HTTP 等）；协议细节以实际实现和版本为准。
- 参数包括服务器名称、启动命令或 URL、环境变量/认证引用、超时、自动连接。
- 连接后枚举工具、名称、描述、输入 Schema、注解；允许单独停用或屏蔽危险工具。
- 记录运行状态、最近失败、重启次数与最近成功调用时间。

## 授权

- 默认新服务器只有管理员可见，所有 Bot/会话不自动获得其工具。
- 支持为全局、Bot、会话配置具体工具白名单；平台或会话权限不能提升被管理员全局禁用的高危权限。
- 对涉及外部写入或信息外发的工具定义确认策略：始终允许、首次确认、每次确认、禁止（实际实现时还需可信权限判定）。

## 安全限制

- 本地 stdio 进程天然可能有主机权限，插件权限不是 OS 沙箱；需限制执行身份和环境变量范围。
- 外部 HTTP Tool 可能造成 SSRF、数据外传；可配置出站地址白名单与请求限制。
- 不应把服务器的认证密钥、环境变量原文写入常规日志。
- 某个 MCP 服务异常要能够超时、中断和断路，不阻塞所有群的 Agent。

## 验收

- 能连接一个服务，选择单个工具授予测试会话，再在模拟聊天里调用。
- 未授权会话的 Agent Tool 列表中完全没有该工具。
- 服务断开会在 MCP 列表与调试 Trace 中明确提示，且不会无限重试。
