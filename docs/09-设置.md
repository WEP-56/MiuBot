# 设置 · 全局配置与维护

**位置**：侧栏底部 / 设置 · **目标**：统一管理工作台、部署运行、安全、存储、更新与诊断选项。

## 页面布局

左侧设置目录（页内）：`通用 / 运行与网络 / 数据与备份 / 安全 / 日志 / 关于与更新`。避免把提供商、平台、人设相关业务配置重新复制一遍。

## 设置分区

| 分区 | 主要配置 |
|---|---|
| 通用 | 语言、主题、时区、数字格式、默认首页周期 |
| 运行 | 服务绑定地址、允许来源、并发限制、自动重连的全局默认策略 |
| 数据与备份 | SQLite 数据位置（显示）、备份/恢复、保留天数、存储用量、清理 |
| 安全 | 工作台身份验证、管理员会话、密钥加密策略、权限审核入口 |
| 日志 | 等级、脱敏、采样、轮转、保留期限 |
| 关于 | Miubot 版本、Pi Fork 基线、插件接口版本、更新说明与诊断信息 |

## 安全要点

- 工作台默认不应该无认证地对公网开放；远程访问需明确身份验证和 TLS 部署建议。
- 密钥属于服务端秘密；前端只可提交更新，不能批量读取明文。
- 备份可能包含 QQ 凭据、Prompt、用户消息、长期记忆；默认应强调加密与安全保管。
- 重置、清空、恢复备份等操作需要预览影响范围和明确确认。

## 操作状态

保存后即时生效的选项要有状态反馈；需要重启的选项显示“已保存，重启后生效”。恢复备份前检查版本与结构兼容性，必要时提供迁移预览。

## 验收

- 基础运行设置明确分类，业务实体仍回到各自页面管理。
- 工作台远程开放时有明确安全提示或保护措施。
- 可备份与恢复配置；危险操作不能被误触一键执行。
