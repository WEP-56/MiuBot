# 首页 · 概览

**位置**：侧栏 / 首页 · **目标**：立即判断能否工作、成本和消息量如何、该去哪里处理问题。

## 页面结构

```text
概览                                      [24h / 7d / 30d] [刷新]
[收到消息] [Bot 回复] [Token 消耗] [估算成本]
[ 消息量/Token 趋势图                        ]
[Bot 连接状态              ] [提供商与模型状态       ]
[默认人格                 ] [最近异常 / 快捷入口     ]
[最近活动/关键 Trace                                 ]
```

## 核心区块

| 组件 | 信息与交互 | 优先级 |
|---|---|---|
| 指标卡 | 收到消息数、已发送回复数、Token、估算成本；可选请求数 | P0 |
| Bot 状态 | 显示每个实例名称、平台、在线/重连/异常、详情入口 | P0 |
| 提供商卡 | 提供商数、模型数、可用与不可用模型；配置入口 | P0 |
| 人格卡 | 默认人格名称、数量、编辑入口 | P0 |
| 趋势图 | 选择按消息量、Token 或请求次数查看 | P1 |
| 活动与错误 | 最近连接异常、模型失败、重要 Trace | P0 |

## 数据口径

- 收到消息：去重后进入 Miubot 的入站消息；记录来源平台与 Bot。
- Bot 回复：Miubot 确认进入发送流程并得到平台成功回执的消息；与模型生成次数分离。
- Token：以 API 回传的 usage 为优先；估算值需标“估算”。
- 费用：按用户指定或提供商可用价格计算，只提供估算；缺失价格不纳入“精确总费用”。
- 成功率：区分模型请求成功率与消息发送成功率，显示统计窗口与样本数。

## 空、错、慢状态

- 初次安装：出现“连接平台 → 添加提供商 → 创建/选人格”的引导卡，可跳过。
- 平台离线：卡片显示最近错误和“查看平台”入口，不能笼统显示“系统正常”。
- 统计不存在：显示“暂无数据”，不用虚构 `0%` 成功率。
- 统计查询超时：其他模块仍可显示，单卡片局部报错并允许重试。

## 验收标准

- 首页所有快捷入口指向正确对象及页面；统计卡有统一时间范围。
- 未连接平台/未配置模型时，可以完成下一步操作。
- 使用样例数据仅发生在设计或演示模式，不进入真实统计。
