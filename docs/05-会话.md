# 会话 · 群聊与私聊管理

**位置**：侧栏 / 会话 · **目标**：查看真实聊天、管理聊天上下文，并为不同群/个人设置独立的 Agent 行为。

## 页面结构

```text
会话                         [群聊 | 私聊] [Bot 筛选] [搜索]
列表：头像、会话名、平台、最近消息、未处理状态、开关
  点击会话 → 详情
    ├─ 聊天记录
    ├─ 会话配置
    ├─ 上下文与记忆
    └─ 最近执行 / Trace
```

## 会话主键与边界

会话唯一定位建议使用 `(platformId, botInstanceId, conversationType, externalConversationId)`；群成员使用额外的 `(platformId, externalUserId)` 身份，并保留来源平台范围。不同 Bot 在同一群不应意外共享会话执行上下文；跨 Bot 共享必须显式设计。

## 聊天记录

- 按时间显示消息、发言者、引用关系、图片与语音占位、Bot 回复及发送状态。
- 允许检索、按发言者/消息类型过滤、查看某条消息的原始事件摘要。
- Bot 回复旁显示所用人格/模型概况和 Trace 入口。
- 管理员能选择删除对话历史、导出授权范围内的记录；删除与上下文/记忆保留关系必须说明。

## 会话配置

| 分组 | 配置 |
|---|---|
| 基础 | 会话名称备注、是否启用、静默/免打扰、可回复范围 |
| 触发 | @、引用、命令、关键词、智能插话；单聊默认规则 |
| Agent | 人格、普通聊天模型、各任务模型覆盖、额外会话指令 |
| 能力 | 搜索、生图、音频、表情包、Skills、MCP/Tool 授权 |
| 上下文 | 最近历史、时间跨度、Token 预算、摘要策略、长期记忆范围 |
| 频率 | 冷却、每小时/日限额、并发、预算上限 |
| 权限 | 允许/拒绝用户、管理员能力、特殊成员规则 |

### 配置继承

采用 `全局默认 → Bot 实例 → 当前会话 → 群内特定成员（仅适用字段）`。**展示实际值与来源**；一个值不允许“复制默认值”假冒继承。成员级规则只影响本成员触发、能力和权限等有定义的字段，不覆盖整个群级系统状态。

```text
智能插话：继承 Bot 默认（开启）   [自定义]
人格：Miu 〔当前会话覆盖〕       [恢复继承]
生图能力：全局禁止（锁定）       [查看原因]
```

限制性权限规则采用不可被下层提升的边界：高层明确禁止的高危工具，群内不能通过覆盖重新打开。

## 上下文 / 记忆

- **原始历史**：可浏览、检索与按授权删除的完整事件/消息。
- **运行上下文**：一次请求实际提供给 Agent 的片段，可以在调试台查看组装结果。
- **长期记忆**：摘要/事实/偏好记录，有来源、范围与修改删除入口。

群聊原始历史不是无限制 Prompt；由 Context Core 依据时间、引用链、参与者、相关性、预算动态选取。

## 多人群聊需要注意

- 同时收到多个 @ 或新消息时，为群配置串行/排队、取消过时回复或并发策略。
- 回复期间出现新消息，允许标记是否重新取上下文；避免 Bot 对早已结束的话题迟到插话。
- @、引用、昵称和真实消息段由适配器标准化，不靠字符串猜测。
- 记忆不得从私聊泄漏至群聊，也不得擅自跨群共享。

## 空状态和异常

无记录时引导发送第一条消息；Bot 下线则会话仍可浏览，但显示实时回复不可用。模型/人格被删除时明确显示悬空引用，不静默替换。

## 验收

- 可为两个群分别设置模型/人格/触发方式，且不会串上下文。
- 会话显示配置继承来源，一键恢复默认有效。
- 能从每次 Bot 回复直达执行 Trace，并区分生成失败与发送失败。
