# 平台适配与能力模型

## 目的

让 Miubot 内核只接触标准化消息与能力声明，而非直接依赖 QQ 官方或 OneBot 的具体事件格式。

## 三层概念

- **平台**：目标通信平台，如 QQ。
- **适配器**：某个平台/协议的一种实现，如官方 API 或 OneBot v11 接入。
- **Bot 实例**：拥有唯一配置、身份、连接状态的实际连接对象。

## 适配器接口（概念）

```ts
interface PlatformAdapter {
  kind: string;
  getSetupSchema(): SetupSchema;
  connect(config: RedactedConfigRef, signal: AbortSignal): Promise<Connection>;
  disconnect(): Promise<void>;
  getIdentity(): Promise<BotIdentity | null>;
  getCapabilities(): Promise<CapabilityReport>;
  send(target: ConversationTarget, message: OutboundMessage): Promise<SendResult>;
  onEvent(handler: (event: NormalizedEvent) => void): Unsubscribe;
}
```

这是设计契约，不是已经定义或可运行的 SDK 类型。

## 标准化事件

公共字段：`eventId, platformId, adapterId, botInstanceId, conversationId, actorId, timestamp, messageId, segments, replyTo, rawEventRef, traceId`。

Segment 可表示纯文本、@、表情、图片、音频、引用、文件和未知结构。原始事件可脱敏保存用于调试，但业务代码优先使用标准化结构。

## 能力声明

各项为 `supported | unsupported | unknown`，必要时增加权限范围：

- 收到群/私聊文本、图片、语音。
- 发送文本、图片、语音、文件、@。
- 接收引用/回复、撤回、成员事件。
- 主动发送消息（push）、获取群/成员资料。
- 账号登录方式（密钥、扫码、WebSocket）、断线重连。

**能力来自适配器报告与实际验证**，不得仅凭“QQ”推断可用。

## 接入安全

- 连接凭据加密/受保护存储，不出现在一般日志里。
- 反向 WebSocket 默认只监听本机；绑定公网需提示认证和网络风险。
- 事件去重，限制单消息体大小、附件下载体积、媒体格式。
- 发送动作做能力检查、权限检查、速率限制和幂等保护。
- 实例身份变更需显式审查会话归属。

## 对产品层的影响

平台页面根据 `SetupSchema` 动态生成字段；会话与 Agent 根据能力声明隐藏不可用功能或提示降级。例如适配器不支持发送语音时，语音相关配置应标注不可用，不能静默吞掉输出。
