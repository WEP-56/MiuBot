# 平台 · Bot 实例管理

**位置**：侧栏 / 平台 · **目标**：连接 QQ 及后续其他平台，清楚知道实例可用状态和具备何种消息能力。

## 页面结构

```text
平台                         [+ 添加 Bot] [搜索] [筛选状态]
[ Bot 列表：头像 | 名称 | 平台/适配器 | 状态 | 最近事件 ]

点击实例 → Bot 详情
  ├─ 概览（连接、心跳、最近消息、能力）
  ├─ 连接配置（端点、凭据、重连）
  ├─ 行为默认项（默认人格、模型/路由引用、启用范围）
  └─ 连接事件（协议日志、心跳、认证与重试）
```

## 实例卡片

展示 Bot 名称/头像、平台与适配器名称、连接状态（连接中、在线、降级、断开、禁用）、最后一次事件/心跳、快速查看按钮。列表允许按平台、状态、名称筛选；删除和停用进入“更多”。

## Bot 详情页

1. **概览**：适配器版本、账号信息（能力允许时）、最近心跳、接收/发送状态、最近错误。
2. **连接**：显示认证方式与连接参数；敏感字段默认掩码；测试、重连、停用、删除。
3. **能力**：文本、图片、语音、@、撤回、主动消息等；状态值为 `支持 / 不支持 / 未验证`，不凭平台名推断。
4. **默认配置**：默认人格、消息处理开关、模型策略继承；实际群聊覆盖在会话页面编辑。
5. **连接事件**：低层协议和认证事件，带 Trace 跳转；完整聊天在「会话」，跨模块日志在「运行日志」。

## 状态模型

| 状态 | 含义 | UI 行为 |
|---|---|---|
| 未配置 | 参数尚未保存完成 | 引导继续填写 |
| 连接中 | 建立网络或等待认证 | 展示阶段与取消 |
| 已连接 | 握手/认证完成且连接有效 | 显示接入能力、最近心跳 |
| 降级 | 连接存在但消息收发/心跳异常 | 告警并支持诊断 |
| 已断开 | 连接失败或中断 | 显示错误、重试与编辑 |
| 已停用 | 用户主动关闭实例 | 不重连、不处理消息 |

## 操作边界

- 停用：保留配置、历史、会话映射；不再接收/发出业务消息。
- 删除：明确是否只删除实例配置、是否同时清理历史；强制二次确认。
- 重新连接：不会静默更换账号；识别 Bot 身份变更时提示核对。
- “发送测试消息”必须选择目标会话并显式确认，不能默认向真实群发消息。

## 验收

- 用户可以添加、修改、重连、停用和删除一个 Bot 实例。
- 连接失败时能确定失败属于端点、认证、协议、心跳还是收发阶段。
- 可以从实例卡片抵达其真实会话与连接日志。
